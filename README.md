# Soso-self-media 家居建材自媒体实验室

> 单人自媒体降维打法——用 AI 搞定从选题到初稿的整套运营工作流。

聚焦赛道：**家居建材 → 全屋定制 → 板材**

支持平台：**抖音 + 小红书**

数据来源：**Firefly 社媒数据 API**

---

## 功能概览

四大核心模块，可独立使用，也可串联走完整工作流：

| 模块 | 功能 | 核心输入 | 核心输出 | 单次成本（抖音） |
|------|------|----------|----------|-----------------|
| 选题挖掘 | 搜热门、挖选题 | 关键词/领域 | 候选选题清单 | 13 积分 |
| 对标分析 | 拆账号、找规律 | 账号链接/ID | 账号拆解报告 | 4 积分/账号 |
| 爆款拆解 | 拆结构、提模板 | 3-5 条爆款链接 | 结构模板 + 钩子模板 | 60 积分/5条 |
| 初稿生成 | 套模板、出初稿 | 选题 + 模板 + 人设 | 内容初稿 | 0 积分 |

**完整走一轮成本（抖音）**：约 81 积分 ≈ ¥0.81

## 快速开始

### 安装

将 `Soso-self-media` 文件夹放入你的 TRAE skills 目录：

```
.trae/skills/Soso-self-media/SKILL.md
```

### 首次使用

第一次调用 Skill 时，会引导你配置以下信息（只需要配置一次，后续对话自动记忆）：

1. **Firefly API Key**（在 [firefly.qwjxqn.xyz](https://firefly.qwjxqn.xyz) 注册获取）
2. 主要平台（抖音/小红书）
3. 账号人设
4. 产品/品牌信息

### 使用方式

直接向 Skill 描述你的需求，例如：

- "帮我找一下板材赛道最近的热门选题"
- "帮我分析一下@锐哥聊装修这个账号"
- "帮我拆解这几条爆款视频的结构"
- "帮我写一个板材避坑的视频初稿"

## 底层方法论

核心思维：**拆解 → 复用 → 创新**

1. **数据驱动**：用爆款数据验证方向，不凭感觉做决策
2. **结构化复用**：把爆款规律提炼成模板，提高效率和质量下限
3. **人设差异化**：结构可以借鉴，但要用个人经历和观点建立独特性
4. **人机协作**：AI 做信息收集和初稿生成，人做方向判断和创意把关

## 成本说明

Firefly 采用积分制，1 积分 ≈ ¥0.01。

| 接口 | 抖音 | 小红书 |
|------|------|--------|
| 搜索 | 13 积分/次 | 13 积分/次 |
| 详情 | 10 积分/次 | 10 积分/次 |
| 评论 | 2 积分/次 | 2 积分/次 |
| 账号信息 | 2 积分/次 | 2 积分/次 |
| 账号作品 | 2 积分/次 | 2 积分/次 |

**省钱技巧**：
- 优先用账号作品接口批量获取（2 积分 vs 搜索 13 积分）
- 抖音比小红书便宜，先抖音找对标，再小红书深扒
- 搜索尽量精准，减少无效调用
