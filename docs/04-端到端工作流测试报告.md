## 四、初稿生成

### 测试内容
- 选题方向：全屋定制板材避坑
- 使用模板：模板 1（数字遍历式避坑清单）
- 注入人设：板材行业从业者（18年经验）
- 积分消耗：0（纯 LLM 生成）

### 生成的内容初稿

**标题**：全屋定制选板材，这5个坑踩了就是给商家送钱

**时长**：约 2 分钟

**脚本**：

```
【钩子 0-5秒】
全屋定制选板材，记住这5个坑，踩了就是给商家送钱。
做板材18年，今天说点行业内幕。

【第1坑：环保等级文字游戏 5-30秒】
第一个坑，环保等级的文字游戏。
商家说"E0级环保"，你以为是国标E0？
错！很多商家用的是企业标准E0，门槛比国标低得多。
正确做法：认准国标GB/T 39600-2021，ENF级才是最高，E0级是底线。
让他拿出检测报告，看CMA认证章。

【第2坑：颗粒板冒充实木 30-55秒】
第二个坑，颗粒板冒充实木多层板。
表面看一模一样，价格差3倍。
颗粒板用的木屑胶水压制，成本低，握钉力差。
实木多层板是真实木皮层压，强度高，防潮好。
正确做法：看横截面，颗粒板是碎屑状，多层板是层状纹理。让商家当场切个角看。

【第3坑：生态板不生态 55-85秒】
第三个坑，生态板不一定"生态"。
"生态板"只是行业俗称，跟环保没关系。
有的生态板内部用的是劣质芯材，甲醛超标。
正确做法：看板芯，杉木芯和杨木芯比较好。闻味道，刺鼻的别要。还是要看检测报告。

【第4坑：品牌混淆 85-115秒】
第四个坑，品牌混淆。
商家说"我用的是爱格板"，但你问他是爱格哪个系列？
爱格有国产线和进口线，价格差一倍。
还有商家说"福人板"，但你用的是福人精板还是福人素板？
正确做法：问清楚品牌全称、系列名、产地，写进合同。

【第5坑：背板偷工减料 115-145秒】
第五个坑，背板偷工减料。
合同写"9mm背板"，实际给你装5mm的。
你不开柜子看根本发现不了，5mm背板容易变形发霉。
正确做法：验收时用尺量背板厚度，拍照留证。合同写清楚"品牌+厚度+规格"。

【结尾 145-155秒】
做板材18年，这些坑我见太多了。
关注我，下期讲怎么花同样的钱买到更好的板材。
```

**话题标签**：#全屋定制 #板材避坑 #装修避坑 #板材怎么选 #装修干货

### 优化建议
1. 开头5秒可以加一个"翻车案例"画面增强代入感
2. 每一坑之间用"第X个坑"做明确分割，方便用户跳看
3. 结尾引导评论区互动："你家全屋定制踩了哪个坑？评论区说说"
