### 阶段2：挖掘选题（00:54 - 01:22）

**目标**：生成候选选题清单

**操作要点**：
1. 调用自媒体调研 Skill
2. 搜索相关领域内容
3. 输出候选选题清单

**选题挖掘维度推测**：
- 平台热门话题/热搜

---

### 阶段3：研究对标账号（01:22 - 02:01）

**目标**：生成对标账号拆解报告

**输入**：
- 爆款视频链接
- 博主主页链接

**操作要点**：
1. 发送对标账号链接给 WorkBuddy
2. WorkBuddy 整理账号信息
3. 生成账号拆解报告

**拆解维度推测**：
- 账号基础信息（粉丝数、获赞数、作品数）
- 账号定位与人设分析
- 内容主题分类与占比
- 内容风格与表现形式
- 发布频率与发布时间规律
- 爆款作品特征分析
- 互动数据表现（点赞/评论/转发/收藏）
- 变现方式与商业路径

**输出物**：账号拆解报告（结构化文档）

---

### 阶段4：拆解爆款结构 + 生成初稿（02:01 - 03:10）

**目标**：从爆款中提炼规律，生成自己的内容初稿

**操作要点**：
1. 提炼高频选题方向
2. 分析开头钩子
3. 拆解内容结构
4. 加入自己的人设和经历
5. 生成专属视频初稿

**爆款拆解要素**：

| 要素 | 说明 |
|------|------|
| 高频选题 | 哪些选题方向反复出爆款 |
| 开头钩子 | 前3秒/前30字如何吸引注意力 |
| 内容结构 | 起承转合的节奏和逻辑 |
| 金句/亮点 | 视频中的高光时刻和记忆点 |
| 结尾引导 | 如何引导互动/关注/转发 |

**生成初稿的逻辑**：
- 结构复用：借用爆款的结构框架
- 内容替换：填入自己的领域知识
- 人设注入：加入个人经历、观点、风格
- 本土化：适配自己的账号定位和受众

**输出物**：视频/内容初稿（脚本文案）

## 四、方法论底层逻辑

### 核心思维：拆解 → 复用 → 创新

```
爆款样本 → 结构拆解 → 规律提炼 → 模板复用 → 个性注入 → 新内容
```

### 关键原则

1. **数据驱动决策**
   - 不凭感觉做选题
   - 用爆款数据验证方向
   - 基于对标账号做决策

2. **结构化复用**
   - 爆款是有规律的
   - 把规律提炼成可复用的模板
   - 用模板提高产出效率和质量下限

3. **人设差异化**
   - 结构可以抄，人设不能抄
   - 在复用结构的基础上注入个人特色
   - 用个人经历和观点建立独特性

4. **人机协作**
   - AI 做：信息收集、数据整理、结构分析、初稿生成
   - 人做：方向判断、质量把关、人设注入、创意决策
